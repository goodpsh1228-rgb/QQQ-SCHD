# QQQ · SCHD · SPY 포트폴리오 백테스트

QQQ, SCHD, SPY의 **비중**과 **비용**을 조절해 보면서 과거 수익률과 최대낙폭(MDD)을 차트로 확인하는 웹사이트입니다.

## 할 수 있는 것

- 세 ETF의 비중 조절 (슬라이더 또는 숫자 입력, 합계가 100이 아니면 비율대로 환산)
- 비용 설정: ETF별 연간 추가 비용(%), 매수·매도할 때 드는 거래비용(%)
- **적립식 투자**: 처음 넣는 돈 + 매월 적립금 (매월 첫 거래일에 목표 비중대로 매수)
- **세금 반영** (해외주식 직투·일반 계좌 기준): 배당소득세, 양도소득세(연 250만원 기본공제), 종료일 전량 매도 가정
- 리밸런싱 주기: 안 함 / 매월 / 분기 / 매년
- 기간: 전체 / 최근 10·5·3·1년, 또는 시작일·종료일 직접 지정
- 결과: 자산 가치 추이, 낙폭(drawdown) 차트, 연도별 수익률, 성과 비교표, 기간별 수익률 표
- 각 ETF를 100% 보유했을 때와 비교

## 계산 방식

- **가격 데이터**: Yahoo Finance의 일별 종가와 배당금으로 만든 *총수익 지수*(배당 재투자·주식 분할 반영). 배당락일별 배당수익률도 함께 저장해 배당소득세 계산에 씁니다.
- **ETF 운용보수**(QQQ 0.20%, SCHD 0.06%, SPY 0.0945%)는 이미 가격에 반영돼 있습니다. 화면의 "추가 비용"에는 환전 수수료 같은 그 밖의 비용을 넣으면 됩니다.
- **적립식일 때 수익률 보는 법**
  - **CAGR·MDD·연도별 수익률**은 펀드 기준가처럼 적립금 입금 효과를 뺀 "운용 성과"로 계산합니다. 그래서 같은 전략이면 적립금 크기와 상관없이 같게 나옵니다.
  - **IRR(실제 연수익률)**은 언제 얼마를 넣었는지까지 반영한 "내 돈 기준" 연수익률입니다. 적금 금리처럼 생각하면 됩니다.
- **세금 계산 방식** (단순화한 모델)
  - 배당소득세: 배당을 받을 때 15%(미국 원천징수)를 떼고 나머지를 재투자
  - 양도소득세: 리밸런싱 등으로 매도해 생긴 1년치 손익을 합산 → 250만원 공제 → 22%. 다음 해 첫 거래일에 보유 자산 일부를 팔아 낸다고 가정 (실제 납부는 5월)
  - 취득가는 평균단가 기준, 재투자한 배당은 취득가에 포함
  - 환율 변동, 금융소득종합과세(연 2,000만원 초과), 손실 이월공제(한국은 불가)는 반영하지 않습니다
  - ISA·연금저축 계좌는 과세 방식이 달라 이 계산과 맞지 않습니다
- 주요 지표
  - **CAGR (연평균 복리수익률)**: 매년 같은 비율로 불어났다고 쳤을 때의 1년 수익률
  - **MDD (최대낙폭)**: 이전 최고점에서 가장 많이 떨어졌을 때의 하락률. 예) -30% = 1,000만원이 700만원까지 내려간 적이 있음
  - **변동성**: 하루하루 수익률이 얼마나 출렁이는지를 1년 기준으로 환산한 값
  - **샤프지수**: CAGR ÷ 변동성. 위험(출렁임) 1만큼을 감수하고 얻은 수익. 클수록 효율적 (무위험수익률 0으로 가정)

## 폴더 구조

```
index.html                 화면 뼈대 (입력칸, 차트 자리, 표 자리)
css/style.css              디자인 (색상, 배치, 다크모드)
js/backtest.js             백테스트 계산 (수익률, MDD 등)
js/app.js                  입력 읽기 → 계산 호출 → 차트·표 그리기
data/prices.json           가격 데이터 (자동 생성)
scripts/fetch_data.py      가격 데이터를 받아 prices.json을 만드는 파이썬 스크립트
.github/workflows/update-data.yml   매주 데이터를 자동 갱신하는 GitHub Actions 설정
```

## 내 컴퓨터에서 실행하기

`index.html`을 더블클릭해서 열면 브라우저 보안 정책 때문에 데이터 파일을 읽지 못합니다. 간단한 로컬 서버를 띄워서 여세요.

1. 터미널(명령 프롬프트)을 열고 이 폴더로 이동합니다.
   ```bash
   cd QQQ-SCHD
   ```
2. 데이터 파일이 없다면 먼저 받습니다. (파이썬 필요)
   ```bash
   pip install yfinance
   python scripts/fetch_data.py
   ```
3. 로컬 서버를 실행합니다.
   ```bash
   python -m http.server 8000
   ```
4. 브라우저에서 <http://localhost:8000> 을 엽니다.

## 인터넷에 공개하기 (GitHub Pages, 무료)

1. GitHub 저장소 → **Settings** → **Pages**
2. **Source**: `Deploy from a branch`, **Branch**: 공개할 브랜치 / `/ (root)` 선택 → Save
3. 1~2분 뒤 표시되는 주소(`https://<아이디>.github.io/<저장소명>/`)로 접속

## 데이터 갱신

`.github/workflows/update-data.yml`이 매주 월요일 자동으로 `scripts/fetch_data.py`를 실행해 `data/prices.json`을 커밋합니다. 바로 갱신하려면 저장소의 **Actions** 탭 → *Update price data* → **Run workflow**를 누르세요.

> 과거 성과가 미래 수익을 보장하지 않습니다. 투자 판단의 참고용으로만 사용하세요.
